Comment fonctionne le NFC ?Kijan NFC la mache?

Une petite puce est cachée dans l’objet. Quand vous approchez un téléphone compatible, il ouvre automatiquement une page web personnalisée.Gen yon ti chip kache nan objè a. Lè ou pwoche yon telefòn ki konpatib, li louvri otomatikman yon paj entènèt pèsonalize.

Faut-il installer une application ?Eske nou dwe enstale yon aplikasyon?

Non. La page s’ouvre dans le navigateur du téléphone.Non. Paj la louvri nan navigatè telefòn nan.

Que faire si le téléphone ne lit pas le NFC ?Kisa pou fè si telefòn nan pa li NFC a?

Vérifiez que le NFC est activé (surtout sur Android), retirez une coque épaisse et approchez lentement le haut du téléphone du symbole NFC. Sinon, utilisez le QR code lorsqu’il est proposé.Verifye si NFC a limen (sitou sou Android), retire yon kouvèti epè epi pwoche tèt telefòn nan dousman sou siy NFC a. Sinon, sèvi ak kòd QR a lè yo ofri l.
